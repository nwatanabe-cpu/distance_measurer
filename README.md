# Simple Distance Measurer

QGIS上で、地図上の距離、ポリゴンの面積、ライン地物の総延長を計測するプラグインです。

アクティブレイヤーまたはキャンバスのCRSに合わせて測地計算を行い、計測結果を地図キャンバス上に表示します。楕円体にはGRS80を使用します。

## 機能

- **距離計測**: 地図上に複数の点を指定し、折れ線の距離を計測
- **面積計測**: ポリゴンレイヤーの地物を範囲選択し、合計面積を計測
- **ライン延長計測**: ラインレイヤーの地物を範囲選択し、総延長を計測
- 測定対象をキャンバス上でハイライト表示
- レイヤーCRSとキャンバスCRSが異なる場合も座標変換して計測

## 動作環境

- QGIS 3.0 以降
- ベクターレイヤー（面積計測またはライン延長計測を使用する場合）

## インストール

### QGISプラグインフォルダーへ配置する場合

1. このリポジトリをダウンロードまたはクローンします。
2. `distance_measurer` フォルダーをQGISのプラグインフォルダーへコピーします。
3. QGISで **プラグイン > プラグインの管理とインストール** を開きます。
4. **インストール済み** の一覧から **Simple Distance Measurer** を有効にします。

QGISのユーザープラグインフォルダーは、通常、次の場所にあります。

- Windows: `%APPDATA%\\QGIS\\QGIS3\\profiles\\default\\python\\plugins`
- macOS: `~/Library/Application Support/QGIS/QGIS3/profiles/default/python/plugins`
- Linux: `~/.local/share/QGIS/QGIS3/profiles/default/python/plugins`

## 使い方

プラグインを有効にすると、QGISのツールバーに次の3つのボタンが追加されます。

### 距離計測

1. **距離計測(m)** をクリックします。
2. 地図キャンバス上で左クリックして、計測する折れ線の頂点を追加します。
3. マウスを動かすと、現在位置までの距離が表示されます。
4. 右クリックで計測をリセットします。
5. `Esc` キーで最後に追加した点を1つ戻せます。

距離はキャンバスのCRSを基準に計測し、メートルで表示します。

### 面積計測

1. 面積レイヤーをアクティブにします。
2. **面積計測(ha)** をクリックします。
3. 地図キャンバス上で左ドラッグして、対象のポリゴンを含む範囲を指定します。
4. 選択された地物の合計面積がヘクタール（ha）で表示されます。
5. `Ctrl` を押しながら範囲を指定すると、追加選択または選択解除ができます。
6. 右クリックで選択をリセットします。

### ライン延長計測

1. ラインレイヤーをアクティブにします。
2. **ライン延長計測(m)** をクリックします。
3. 地図キャンバス上で左ドラッグして、対象のラインを含む範囲を指定します。
4. 選択されたラインの総延長がメートルで表示されます。
5. `Ctrl` を押しながら範囲を指定すると、追加選択または選択解除ができます。
6. 右クリックで選択をリセットします。

## CRSと計測について

- 面積とライン延長は、アクティブレイヤーのCRSを基準に計測します。
- 距離は、地図キャンバスの表示CRSを基準に計測します。
- レイヤーCRSとキャンバスCRSが異なる場合、選択範囲とハイライトの座標を自動的に変換します。
- 測地計算にはGRS80楕円体を使用します。
- 面積の表示単位はha、距離とライン延長の表示単位はmです。

## 注意事項

- 面積計測には、アクティブなポリゴンレイヤーが必要です。
- ライン延長計測には、アクティブなラインレイヤーが必要です。
- 範囲選択では、指定した矩形に含まれる地物が対象になります。
- 計測結果は地図キャンバス上に表示されます。別途ファイルへ書き出す機能はありません。
